# Threat model

Untrusted model output, caller-supplied risk, role spoofing and unknown tools are primary threats. Policy and principal must come from authenticated, trusted host configuration; the model only proposes a tool. Invalid policies and requests deny. Critical risk denies; medium/high require review. Deny wins over review and allow. No execution adapter or approval consumption exists yet. CLI fixtures are not trusted identities. Do not use as a standalone enforcement boundary. Restrict access to policy files and gate every side effect in the host. Prompt-injection detection is not a security guarantee. The API accepts plain JSON data, not executable objects or proxies. CLI accepts trusted local file paths only; input is limited to 64 KiB per file and regular files.
