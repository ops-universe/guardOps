# Durable local governance

Explicitly initialize each store once in a trusted private local directory (0700) with a host-managed random key of at least 32 bytes. Do not initialize on missing state during normal operation. The authenticated snapshot is written using a private temporary file, fsync, rename and directory fsync. Exclusive lock files serialize transactions; a crash-stale lock fails closed until a trusted administrator investigates. Never automatically remove a stale lock. HMAC authenticates state and separates audit and approval domains. Restart preserves consumed approvals and clock high-water mark. This is not distributed storage, rollback-resistant storage or a substitute for external checkpoints: restoring an older correctly authenticated snapshot can restore old state. Protect the directory and key, avoid network filesystems, establish backup/restore and external checkpoint policies before production. No claim of exactly-once side effects. Approval revisions must match the gateway policy/schema revision. The internalState parameter is trusted implementation data, never model input.
